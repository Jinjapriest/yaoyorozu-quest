八百万クエスト アプリ版（端末保存）

■ 中身
  index.html ............ ゲーム本体
  manifest.webmanifest .. アプリとしての名前・アイコンの設定
  sw.js ................. オフラインでも動かすための仕組み
  icon-*.png / apple-touch-icon.png ... アイコン

  このフォルダの中身を、まとめてそのまま公開してください（ファイル名は変えない）。

■ 公開のしかた（どちらか1つ）
  A. Netlify Drop（いちばん簡単・無料）
     1. https://app.netlify.com/drop を開く
     2. このフォルダをまるごとドラッグ＆ドロップ
     3. 出てきた https://〜.netlify.app のアドレスを友達に送る
     ※ 無料アカウントを作ると、アドレスが消えずに残り、名前も変えられます

  B. GitHub Pages（無料）
     1. GitHubで新しいリポジトリを作り、このフォルダの中身をアップロード
     2. Settings → Pages → Branch を main / (root) にして Save
     3. https://ユーザー名.github.io/リポジトリ名/ が公開アドレス

  ※ https で公開する必要があります（上の2つはどちらも https です）

■ 友達のスマホへの入れ方
  iPhone ：Safariでアドレスを開く → 共有ボタン → 「ホーム画面に追加」
  Android：Chromeでアドレスを開く → 右上のメニュー → 「アプリをインストール」
           （または「ホーム画面に追加」）
  パソコン：Chrome / Edge のアドレスバー右の「インストール」ボタン

  ホーム画面から開くと、全画面のアプリとして起動します。
  一度開けば、電波がなくても遊べます。

■ セーブについて
  ・セーブデータはその端末の中だけに自動保存されます（サーバーには送りません）
  ・アプリを消す／ブラウザのデータを消すと、セーブも消えます
  ・機種変更や念のための控えは、ゲーム内の「データの書き出し」でファイルに保存し、
    新しい端末で「読み込み」してください
  ・iPhoneでは「Safariで開いたもの」と「ホーム画面のアプリ」でセーブが別々になります

■ claude.ai 版のデータを引き継ぐには
  claude.ai 版で「データの書き出し」→ アプリ版で「読み込み」

■ 更新するとき
  新しい index.html などで同じ場所を上書きすると、
  次に開いたとき（ネットにつながっているとき）に新しい版になります。
